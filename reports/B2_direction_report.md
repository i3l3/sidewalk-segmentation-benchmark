# B2 보행 방향 후보 — 규칙 기반 Baseline

고정 test 이미지: 60장
인도 예측 중 화면 하단 중앙과 연결된 성분만 후보로 사용한다. 차도·자전거도로는 제외한다.
4방향 격자 경로에서 위쪽·좌우 이동만 허용하고, 원본 해상도에서 경로가 후보 영역을 벗어나지 않는지 재검증한다.
연결성·행별 상대 폭·영상 중심 편차·연결 통로 점수를 기록한다. 부족하면 No clear path(판단 보류)다.
화살표는 영상 내 경로이며 실제 거리·통로 폭·안전 경로가 아니다.
임계값은 선언된 기본값이며 방향 검증 라벨로 조정되지 않았다. 테스트 결과로 튜닝하지 않았다.
후보 분포: {'Left': 44, 'Right': 7, 'Straight': 4, 'No clear path': 5}
경로 계산 시간(초, 파일 읽기·시각화 제외): {'mean': 0.0880494585499188, 'median': 0.09126780449969374, 'p95': 0.11347411724996162}
사람이 지정한 방향 라벨이 없어 방향 정확도는 산출하지 않았다. 자동 출력을 정답으로 사용하지 않는다.
3종 모델에는 기타·장애물·연석 분류가 없어 장애물 회피나 보행 안전을 보장하지 않는다.
Decision Tree/Random Forest는 방향별 라벨 수 요건을 충족하지 않아 학습하지 않았다.

## 실제 B2 재추론 측정

Tesla T4, FP32, 배치 1, 입력 512×512, 워밍업 1장 후 고정 테스트 60장을 측정했다. 원본 크기 마스크 복원과 경로 계산을 포함한다. 파일 읽기·모델 로딩·시각화는 이미지별 시간에서 제외한다.

| 단계 | 평균 | 중앙값 | 95백분위 |
|---|---:|---:|---:|
| 전처리 | 19.6 ms | 19.0 ms | 23.8 ms |
| 추론·마스크 복원 | 100.3 ms | 99.4 ms | 105.1 ms |
| 방향 경로 | 88.4 ms | 92.0 ms | 114.7 ms |
| 전체 | 208.3 ms | 212.7 ms | 233.9 ms |

모델 로딩 0.485초, 최대 CUDA 할당 메모리 558.0 MiB.

경로 55/55개가 예측 인도 영역 안에 있는 것을 검사했다. 이는 정답 인도 안에 있다는 의미가 아니다. 재추론 마스크와 저장된 예측은 60장 모두 일치했다. 방향 분포는 왼쪽 44장, 직진 4장, 오른쪽 7장, 판단 보류 5장(8.3%)이다. 왼쪽 후보가 73.3%로 치우쳐 있으며, 방향 정답이 없으므로 장면 분포와 규칙의 편향을 구분할 수 없다. 이 결과로 임계값을 수정하지 않았다. 다음 버전의 조정에는 별도 검증 방향 라벨이 필요하다.
